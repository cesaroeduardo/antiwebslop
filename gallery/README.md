# Slop gallery (era 2026-10)

Static before/after pages built from `tests/fixtures`. Open `index.html` in a browser; no server needed.
Dashed red outlines mark elements `slop-lint` flagged; style-level and file-level findings sit in the
dark bar at the top of each frame.

Rebuild after changing fixtures or rules: `npm run gallery`. The era label is the month the
fixtures were last refreshed. When AI defaults shift, add a new exhibit instead of editing the old one.
