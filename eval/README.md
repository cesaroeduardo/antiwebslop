# Evaluating the skill

Every change to the skill should be measured, not argued. The loop:

1. Write a brief per test project with [`brief-template.md`](brief-template.md) and save it in `briefs/`.
2. Run it with and without the skill following [`ab-protocol.md`](ab-protocol.md).
3. Score both outputs with [`rubric.md`](rubric.md).
4. Log the run in [`VALIDATION.md`](VALIDATION.md).
5. Turn repeated failures into a catalog entry, a lint rule, or a checklist line, and re-run.
