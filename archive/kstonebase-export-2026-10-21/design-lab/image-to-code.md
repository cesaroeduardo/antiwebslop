# Image → code workflow

Skill: `.cursor/skills/image-to-code`.
Inspired by [Leonxlnx image-to-code-skill](https://github.com/Leonxlnx/taste-skill/tree/main/skills/image-to-code-skill).

## Mandatory order (visual tasks)

1. Generate reference image(s) (section-scale, readable)
2. Analyze deeply (extract the system)
3. Implement matching code

Do not start with freeform coding when image generation is available.

## Default dials

`VARIANCE 8 / DENSITY 3 / ART_DIRECTION 8 / IMPLEMENTATION_CLARITY 9 / SPACING 9 / SIMPLICITY 9`

## Image rules

- Large per-section images over one compressed board
- Generate enough (hero + key sections)
- Hero readable on a small laptop
- If unreadable → regenerate before coding

## Extract before coding

Palette, typography, spacing, buttons, geometry, what to **avoid** (nested cards, stickers).

## Afterward

Update `design-knowledge/DESIGN.md` and `design-lab/decision-log`.
